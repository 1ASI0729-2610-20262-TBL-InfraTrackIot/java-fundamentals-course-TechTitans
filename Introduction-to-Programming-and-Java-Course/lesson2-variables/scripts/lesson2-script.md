# Lección 2: Variables y tipos de datos

**Objetivo:** Aprender a guardar información en Java usando variables.

## ¿Qué es una variable?

Una variable es como una caja con nombre donde guardas un dato.
Cada vez que necesites ese dato, usas el nombre de la caja.

**En Java se escribe así:**

```java
int edad = 15;
```

Tres partes: **tipo** → **nombre** → **valor**

## Tipos de datos principales

| Tipo | Para qué sirve | Ejemplo |
|---|---|---|
| `int` | Números enteros | `int vidas = 3;` |
| `double` | Números con decimales | `double precio = 9.99;` |
| `String` | Texto | `String nombre = "Ana";` |
| `boolean` | Verdadero o falso | `boolean aprobado = true;` |

## Ejemplos del mundo real

```java
// App de delivery
String producto = "Pizza";
double precio = 25.90;

// Videojuego
int vidas = 3;
boolean enPartida = true;

// Registro de alumno
String nombre = "Carlos";
int edad = 15;
double nota = 17.5;
```

## Conceptos clave

- El **tipo** le dice a Java qué clase de dato guardarás
- El **nombre** es como llamas a tu variable (sin espacios)
- `String` siempre va entre **comillas dobles**
- `boolean` solo puede ser `true` o `false`
