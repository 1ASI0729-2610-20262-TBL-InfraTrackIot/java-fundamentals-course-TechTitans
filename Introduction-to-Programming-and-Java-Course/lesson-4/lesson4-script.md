# Lesson 4 - Bucles

Hola a todos.

En esta clase vamos a aprender sobre los bucles.

Los bucles sirven para repetir tareas automáticamente.

Por ejemplo, imaginen que quieren mostrar los números del 1 al 10.

Podrían escribir diez líneas diferentes, pero sería mucho más fácil que Java lo haga por nosotros.

Para eso usamos los bucles.

Veamos primero el bucle `for`.

Este código imprime los números del 1 al 10.

Primero tenemos una variable llamada `i` que empieza en 1.

Después tenemos una condición que dice que el bucle continuará mientras `i` sea menor o igual que 10.

Finalmente usamos `i++`, que aumenta el valor de `i` en uno después de cada repetición.

Cuando ejecutamos el programa veremos los números del 1 al 10.

Ahora hagamos algo más interesante.

Vamos a generar la tabla de multiplicar del 5.

En cada repetición Java multiplica 5 por el valor actual de `i`.

Gracias al bucle podemos generar toda la tabla automáticamente.

También existe otro tipo de bucle llamado `while`.

`while` significa "mientras".

Mientras la condición sea verdadera, el bloque seguirá ejecutándose.

En este ejemplo mostramos los números del 1 al 5.

Es importante incrementar la variable porque, de lo contrario, el bucle nunca terminaría.

Para resumir:

* `for` se usa cuando sabemos cuántas veces queremos repetir algo.
* `while` se usa cuando queremos repetir algo mientras una condición siga siendo verdadera.

Los bucles nos ayudan a escribir menos código y automatizar tareas repetitivas.
