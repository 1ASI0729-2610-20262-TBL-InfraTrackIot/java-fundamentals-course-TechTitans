# Lesson 3 - Tomar decisiones con if y else

Hola a todos.

En esta clase vamos a aprender algo que usan prácticamente todos los programas: tomar decisiones.

Por ejemplo, imaginen que están jugando un videojuego. Si tienen suficiente vida, siguen jugando. Si se quedan sin vida, pierden.

O imaginen algo más simple. Si sacan una nota aprobatoria, pasan el curso. Si no, tienen que volver a intentarlo.

Las computadoras hacen exactamente lo mismo usando algo llamado `if` y `else`.

Vamos a empezar con un ejemplo sencillo.

Tenemos una variable llamada edad que vale 20.

Luego usamos una condición para preguntar si la edad es mayor o igual a 18.

Como la condición se cumple, veremos el mensaje "Puedes votar".

Ahora cambiemos la edad a 15.

En este caso aparece una palabra nueva: `else`.

`else` significa "si no".

Si la condición es verdadera, ejecuta el primer bloque.

Si la condición es falsa, ejecuta el segundo.

Por eso ahora veremos el mensaje "Aún no puedes votar".

Para construir condiciones usamos operadores de comparación como:

* Mayor que (`>`)
* Menor que (`<`)
* Mayor o igual que (`>=`)
* Menor o igual que (`<=`)
* Igual que (`==`)
* Diferente de (`!=`)

Veamos otro ejemplo.

Ahora tenemos una nota de 14.

Preguntamos si la nota es mayor o igual a 11.

Como sí lo es, veremos "Aprobado".

Si cambiamos la nota a 8, veremos "Desaprobado".

Y eso es básicamente cómo funcionan las decisiones en Java.

Usamos `if` para hacer preguntas y `else` para indicar qué pasa cuando la condición no se cumple.

Con esto ya podemos crear programas que reaccionan de forma diferente según los datos que reciben.
